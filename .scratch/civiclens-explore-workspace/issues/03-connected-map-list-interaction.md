# 03 — Connected Map and List Interaction

**What to build:** The map and project list behave as one connected interface for hover, keyboard focus, identification, and selection.

**Blocked by:** 01 — Contextual Project Workspace.

**Status:** ready-for-agent

- [ ] List hover and keyboard focus highlight the corresponding map project.
- [ ] Map interaction identifies the corresponding list record.
- [ ] Clicking either surface selects the project and opens project details.
- [ ] Ordinary hover does not automatically scroll the list.
- [ ] Selection, keyboard interaction, and explicit map actions can scroll the selected list record into view when necessary.
- [ ] Selection uses a neutral high-contrast halo, ring, or equivalent treatment.
- [ ] Ordinary selection does not dim unrelated projects or imply suspicion.
