# 07 — Mobile Contextual Workspace

**What to build:** Mobile presents the same project-list/project-details workspace as a bottom-oriented surface rather than a squeezed desktop sidebar or stacked detail layer.

**Blocked by:** 01 — Contextual Project Workspace; mobile presentation decision.

**Status:** ready-for-agent

- [ ] The mobile workspace uses the same list-to-details state model as desktop.
- [ ] Selecting a project replaces the list inside the same bottom-oriented workspace.
- [ ] Project details do not stack a second persistent Sheet over the project list.
- [ ] The selected mobile primitive, snap-point behavior, and expanded-state modality are documented and implemented consistently.
- [ ] The existing Sheet pattern is preferred unless true dragging and snap points justify introducing a separate Drawer dependency.
