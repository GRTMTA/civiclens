# 01 — Contextual Project Workspace

**What to build:** The desktop project area becomes one contextual workspace where `Projects in this view` transitions into `Official project details` when a project is selected.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Selecting a project replaces the project list within the same workspace instead of stacking a project-detail Sheet.
- [ ] `Back to projects` and closing the project return to the list and clear selection appropriately.
- [ ] Existing Community behavior and authorized moderator geometry-review behavior remain available.
- [ ] Overlapping-project resolution remains a temporary dialog rather than a persistent workspace layer.
