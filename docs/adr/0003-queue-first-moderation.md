# Queue-first moderation with map context

**Status: accepted.** Moderation will be organized around a sortable report queue and evidence-review pane, with a map as supporting context rather than the primary index. Moderators need efficient prioritization, evidence comparison, status changes, reasons, and moderation history more than resident-style geographic exploration.

**Consequences:** The moderator UI can reuse table, drawer, and map primitives without becoming a second citizen dashboard; bulk actions and moderation analytics remain out of prototype scope.
