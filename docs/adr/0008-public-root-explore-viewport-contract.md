# Public root official-project map and bounded viewport results

**Status: accepted.** The permanent shadcn application shell will render at `/`, with the official-project map experience as its primary content surface. That surface will publicly browse Official-source project records without requesting device location or requiring sign-in. The map will request a bounded Visible project set for the current Map viewport with a server-controlled prototype limit; a response that reaches that limit must identify itself as a Truncated map result.

The prototype will remove dashboard demo content while retaining the shell's structural and responsive behavior. It will not include observation markers, AI interpretation, scan history, investigation-mode controls, or final CivicLens navigation and branding decisions in this map ticket.

**Consequences:** A narrowly scoped public-safe viewport RPC is required in addition to the authenticated radius-based scan lookup. Its security boundary must use a fixed `search_path`, validated inputs, explicit execution grants, minimal public fields, and no unrestricted anonymous table reads. The map must distinguish an incomplete bounded result from a complete cluster count, and the UI must direct Residents to zoom in when the result is truncated. The initial camera is a Cebu City view and does not depend on browser geolocation. Project selection is authoritative in `project=<id>`; opening a project may create a browser-history entry, while camera parameters use replace-state. A failed configured map style shows a retryable provider state against that same configured provider; a missing `VITE_MAP_STYLE_URL` shows a configuration-required state. Neither case substitutes a fake basemap or unofficial hard-coded tile endpoint.
